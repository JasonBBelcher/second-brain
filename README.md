## Projects

### [AudioForge](projects/audio-forge.md)
Unified music production platform — Electron desktop app with hardware integration (SP-404, EMX-1, Koala), AI audio generation (Stable Audio), stem separation (demucs), audio-to-MIDI, YouTube import, and platform sync.

- **Tech**: Electron 34, Svelte 5, TypeScript, SQLite3, yt-dlp, ffmpeg, basic-pitch
- **Status**: v1.1.0 (production)
- **Key Features**: 35 services, 133+ IPC channels, job queue, 8 DB tables, 45+ UI components

### [Xalpheric Neocities](projects/xalpheric-neocities.md)
Personal creative website on Neocities — generative art, music visualizer, ASCII art, experimental interactive fiction.

- **Tech**: HTML5, CSS3, vanilla JavaScript, p5.js
- **Status**: Active (ongoing experiments)
- **Key Features**: Real-time audio visualization, procedural generation, retro web aesthetics
